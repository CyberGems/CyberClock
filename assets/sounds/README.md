# CyberClock — Audio Assets

## Relax Module — Realistic Ambient Sounds

The Relax module can now play **real recorded audio** instead of procedural synthesis. This makes a massive difference — real rain, ocean waves, and forest ambience are incomparably more immersive.

### How it works
1. Drop MP3 files into this folder (`assets/sounds/`)
2. Name them exactly as listed below
3. Restart CyberClock (or just reopen the Relax window)
4. The engine automatically detects real files and uses them; otherwise it falls back to the built-in synth

### Required filenames
| Filename          | Track Name  | Recommended length |
|-------------------|-------------|--------------------|
| `rain.mp3`        | Rain        | 2–5 min seamless   |
| `ocean.mp3`       | Ocean       | 2–5 min seamless   |
| `night.mp3`       | Night       | 2–5 min seamless   |
| `fireplace.mp3`   | Fireplace   | 2–5 min seamless   |
| `forest.mp3`      | Forest      | 2–5 min seamless   |
| `space.mp3`       | Outer Space | 2–5 min seamless   |

> 💡 **Seamless loops**: Use 2–5 minute recordings that loop cleanly. Longer is fine — the engine loops automatically.

### Search tips
- **Rain**: search "heavy rain loop", "rain on window", "gentle rain"
- **Ocean**: search "ocean waves loop", "seaside waves gentle"
- **Night**: search "night ambience loop", "calm night atmosphere", "night crickets"
- **Forest**: search "forest ambience loop", "birds morning forest"
- **Space**: search "space ambience drone", "cosmic wind deep space"

> ⚠️ Avoid files with music, voices, or sudden loud events. Look for pure ambience / field recordings.

## Alarm Custom Sounds

You can also use this folder for custom alarm sounds, or select any file on your PC via **Settings → Alarms → Custom…**.

### Supported formats
`.mp3` `.wav` `.ogg` `.flac` `.m4a`

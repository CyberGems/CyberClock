# CyberClock — Custom Audio Sounds

Place your custom alarm sound files in this directory.

## Supported Formats
- `.mp3`
- `.wav`
- `.ogg`
- `.flac`
- `.m4a`

## How to Use
1. Open CyberClock Settings → Alarms tab
2. Click **📂 Custom…** next to any alarm
3. Select your audio file

The file path will be saved and used for that alarm slot.

## Built-in Chimes (no files needed)
The following chimes are synthesized procedurally via Web Audio API:

| ID               | Name           | Description                        |
|------------------|----------------|------------------------------------|
| `chime-crystal`  | Crystal Bell   | Four ascending pure sine tones     |
| `chime-digital`  | Digital Pulse  | Square wave two-step beep          |
| `chime-neon`     | Neon Arp       | Sawtooth arpeggiated chord         |
| `chime-zen`      | Zen Gong       | Low sine tone with long decay      |
| `chime-cyber`    | Cyber Sweep    | Sawtooth descending burst          |
